**Shop LOCATION on map — shipped 2026-07-22 (web build + 112 shop/setup/tenant tests green).** User asked: first-time login setup should capture business type + basic info + shop location (lat/lng + city) via a map; "use geoapify for now, google later." Backend was ALREADY ready (tenants table has `business_type, business_category, city_id FK→cities, address, latitude decimal(10,7), longitude decimal(10,7)`; `CompleteSetupRequest` + `UpdateShopRequest` both validate lat/lng as an in-range required-together pair; `CompleteShopSetupAction` persists them). The whole gap was FRONTEND (no map — setup had a city dropdown + address textarea; settings made owners TYPE raw lat/lng numbers).

**Provider abstraction (swap = config change, NOT rewrite):**
- `src/config/maps.ts`: `mapsConfig = { provider: 'geoapify'|'google', geoapifyApiKey, googleMapsApiKey }` read from `VITE_MAPS_PROVIDER / VITE_GEOAPIFY_API_KEY / VITE_GOOGLE_MAPS_API_KEY` (added to `.env` + `.env.example`; dev fallback key `<redacted — see .env, key rotated 2026-08-08>`). Also `MAPS_COUNTRY_BIAS='pk'`, `DEFAULT_MAP_CENTER` (PK centroid 30.3753,69.3451), `DEFAULT_MAP_ZOOM=5`, `PINNED_MAP_ZOOM=16`.
- `src/common/maps/geocoding.ts`: `GeoPlace {lat,lng,formatted,city,state,country,postcode}`; `GeocodingProvider {autocomplete(text,bias), reverse(lat,lng)}`; **GeoapifyProvider** (REST: `api.geoapify.com/v1/geocode/autocomplete|reverse`, `filter=countrycode:pk`, `bias=proximity:`, geojson features → GeoPlace, city falls back city→town→village→municipality→county); **GoogleProvider** = stub that throws "not implemented yet"; `getGeocoder()` factory; `tileLayer()` returns Geoapify raster tiles `maps.geoapify.com/v1/tile/osm-bright/{z}/{x}/{y}.png?apiKey=` + attribution.

**Component:** `src/components/maps/MapPicker.tsx` (uses `leaflet@^1.9.4` + `@types/leaflet`, installed). Interactive Leaflet map (NOT react-leaflet — avoids React 19 peer friction; raw L via refs, `map.remove()` cleanup for StrictMode). Brand `#465fff` teardrop via `L.divIcon` (dodges Leaflet's marker-PNG 404). Features: debounced address autocomplete dropdown, click-to-pin, draggable marker, "Locate me" (navigator.geolocation). Every move reverse-geocodes → `onChange({lat,lng,place})`. Recenter+PINNED_ZOOM only when a pin FIRST appears from an external `value` (so Settings loading a saved pin zooms to it; click/drag never yanks the view). Props: `value:{lat,lng}|null`, `onChange`, `heightClass` (default `h-72`).
