StoreSaleRequest `items.*.price_level` in:retail,wholesale. CreateSaleAction computes `$levelUnit = priceForLevel(...)` then pack uses `$unit->priceUsing($levelUnit)`. wholesale_price wired into Store/UpdateProductRequest + CreateProductAction.
