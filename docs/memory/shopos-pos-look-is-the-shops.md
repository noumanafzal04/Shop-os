2026-10-05. I made the till's bars one quiet grey and removed the top shortcut legend as a "duplicate". The user reversed both within the hour: "why u remove short keys?", "make colour full as was first — POS buttons, keys".

**Why:** a cashier finds Hold as "the amber one"; the legend is where keys are learned. Its removal read as the keys themselves being removed. Printing "⌥P" on a Mac read the same way.
**How to apply:** on the POS keep each action's own hue (KEY_TONE in PosPage) and the top legend; print F-keys everywhere (Alt/Option+letter is an extra in the tooltip/Help). Mobile POS is liked as is — scope visual changes to desktop/tablet. Wanted and kept: ocean ground, bigger bottom bar + text, one-row money bar on desktop.
